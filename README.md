# full-stack-chemistry-learning-

ChemVibe – Eine moderne, interaktive Chemie-Lernplattform mit warmem, menschlichem Design.

## Struktur

- `frontend/` – Nutzer-zentrierte Website (HTML, CSS, JS, Appwrite Web SDK)
- `tech-stack.md` – Tech-Stack, Architektur und Coding-Richtlinien für KI-Agenten und Entwickler

## Erste Schritte

1. Öffne `frontend/index.html` im Browser.
2. Trage in `frontend/app.js` deine Appwrite-Credentials ein (`APPWRITE_CONFIG`).
3. Aktiviere GitHub Pages in den Repo-Einstellungen für das automatische Deployment.

Siehe [`tech-stack.md`](tech-stack.md) für die vollständige Architektur und die Regeln für KI-Agenten.
